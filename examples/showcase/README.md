# 纯文字展示图卡

以下图卡根据本轮实际文字答复排版，供 README、小红书和公众号的本地展示准备。它们不是聊天窗口截图，不使用虚构基线；只裁选原句，不改写答复内容。

每个案例各两张：第一张标为“专业输入”，第二张标为“使用 Skill 的实际文字解释”。输入由官方资料提炼，不是“未使用 Skill 的回复”。生成时还提供了冻结来源摘记；图卡只展示主要专业段落和答复摘录。

- RAG：[输入 PNG](rag-input.png) / [输出 PNG](rag-output.png) / [完整文字](../text-rag.md)
- 重试：[输入 PNG](retry-input.png) / [输出 PNG](retry-output.png) / [完整文字](../text-retry.md)
- [完整同题对照](../text-comparison.md)：本轮两边总体接近，不能宣传稳定领先。

PNG 可直接用于图文排版；同名 SVG 保留可编辑矢量文字。画布为 1080×1440，字体未嵌入，SVG 的外观可能随本机字体变化；PNG 为本次实际导出的固定画面。

现阶段是本地素材，未上传或发布。项目原创图卡采用 MIT 许可，引用的原始资料仍归各自权利人。
