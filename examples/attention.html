自注意力 · 单头教学演示 · 离线可用

一个词，怎样把上下文带进来？

自注意力会让每个位置用自己的“查询”给可访问位置分配权重，再组合那些位置的信息向量。这样，该位置的表示就能带上上下文。这里把例句分成六个示意位置，点一个位置就能查看它的计算。

教学示例：全部向量、权重与连线均由手工数值计算，未读取任何真实模型。较高权重不能证明模型理解了指代，也不能保证答案正确。

点一个位置，看看它能查看谁

例句：“小球滚动，小猫追着它。” 此处按便于讲解的六个片段划分，实际模型使用的 token（文本片段）划分可能不同，句末标点也未展示。

线连接当前查询 Q 与可访问位置的 K；线宽表示教学权重，无箭头。外圈每个位置提供 K 和 V，包括当前位置自己。权重越高，它的 V 在本次组合中所占比例越大。

从匹配到组合，只看这三步

1Q 找 K：先算匹配分数

Q（query，查询向量）是当前位置用于匹配的数值；K（key，键向量）是各位置供它匹配的数值。两者做点积，再缩放，得到分数。

分数 sⱼ = Qᵢ · Kⱼ / √dₖ
本例 dₖ = 2

2softmax：把分数变成权重

softmax把可访问位置的分数变成总和为 1 的非负权重。较高分数会得到较高权重。因果模式先屏蔽后文，再对剩余位置计算权重。

wⱼ = exp(sⱼ) / Σ exp(sₖ)
求和仅含可访问位置

3组合 V：得到注意力输出

V（value，值向量）是各位置实际提供的信息。把每个 V 乘以对应权重，再相加，得到当前位置的注意力输出。

zᵢ = Σ wⱼ Vⱼ

相加的是数值向量，不是文字本身；这里的两个坐标没有人为指定的语义。

这里省略了什么？

真实自注意力层会把每个位置的输入表示 x 经过学到的线性投影，分别产生 Q、K、V：Q = xWQ、K = xWK、V = xWV。同一个位置同时有三者，不会永久被分成“Q 词”“K 词”或“V 词”。本页直接给出手工 Q/K/V，未模拟学习投影的过程。

  • 编码器通常可访问整段输入；因果解码器只能访问当前位置与此前位置。本页用这两种常见范围作比较，固定同一组向量以单独观察 mask（访问限制）的作用。
  • 本页只有一个注意力头、两个向量坐标。多头使用多组投影；完整 Transformer 还包含后续输出投影、残差连接等步骤，这里没有展示。
  • “每个位置形成带有上下文的表示”描述一种计算机制，不代表人的意识，也不代表模型已经理解了句子。
查看本页固定的教学向量与依据

输入选项只有“当前查询位置”和“访问范围”，没有真实模型参数或联网调用。固定向量如下，括号内是两个无单位坐标。

  • 位置 1“小球”：Q = [2, 0]，K = [2, 0]，V = [2, 0]
  • 位置 2“滚动”：Q = [0, 2]，K = [0, 2]，V = [0, 2]
  • 位置 3“，”：Q = [0, 0]，K = [0, 0]，V = [0, 0]
  • 位置 4“小猫”：Q = [1, 1]，K = [1, 0]，V = [1, 1]
  • 位置 5“追着”：Q = [1, 2]，K = [0, 1]，V = [1, 2]
  • 位置 6“它”：Q = [3, 0]，K = [1, 1]，V = [0, 1]

这些整数均是作者为教学选择的假设。比如点击“，”时 Q = [0, 0]，所有可访问位置分数相同，softmax 给它们相同权重；这不代表真实模型中的标点一定平均分配注意力。

概念依据：Vaswani 等 Attention Is All You Need 第 3.2 节（Q/K/V、缩放、权重与组合）与第 3.2.3 节（编码器与解码器的访问范围）。论文链接只在手动点击时打开，网页运行不依赖它。
