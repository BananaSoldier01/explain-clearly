# 验收清单：人工设计用例

本页是预先设计的验收标准，**不是所有项目已执行通过的报告**。实际检查及未验证部分见 [验证记录](../VERIFICATION.md)。逐案评估时仅提供用户请求和必要源资料，不给预期答案。

## 核心验收：自然请求与解释流程

仅给执行者真实用户问题、Skill路径和最少资料，不追加“要易懂”、预期输出、评分或界面设计。观察首答是否直接帮助理解和判断、数字/条件/否定是否保真；只在具体理解障碍需要时建议可视化，说清价值并等对应同意。分别测试同意后产物、拒绝、明确形式、纯交付与混合任务，不强求每例建议图。

这些观察不证明真实用户理解收益或自动触发。详细指定 HTML 的页面质量不作为主要验收门槛。逐案优先隔离，只有同一同意/拒绝链路保留该案上下文；记录共享文件系统/宿主限制。

| 编号 | 请求或上下文 | 应观察的行为 |
| --- | --- | --- |
| T01 | “缓存命中率是啥？” | 第一份答复即用中文定义与具体例子；不把命中率写成准确率 |
| T02 | “为什么命中会快？” | 解释机制与有效前提；不声称每条请求都变快 |
| T03 | “两个方案怎么选？” | 同维度比较；条件缺失不编预算或 SLA |
| T04 | “这个结果是什么意思？”（附虚构报告） | 根据源资料讲结果及限制，不只复述数值 |
| T05 | 只翻译“重试尚未测试” | 仅翻译；不额外接管成解释或建议画图 |
| T06 | 仅润色句子、写诗 | 只做请求任务；不强行定义术语和加来源 |
| T07 | 只交付代码或 JSON | 遵守指定格式；不加技能解释层 |
| T08 | 写函数并解释原理 | 代码交付约定不变；解释部分用本技能 |
| T09 | 解释实际代码分支 | 对照真实代码，不臆造验证、重试和线程安全 |
| T10 | 含多个术语和步骤的方案说明 | 必要时用同一具体情境连接输入、各步变化与输出；不把虚构例子当实际数据，也不强制所有短问题套流程 |
| T11 | “我还是不懂这两步有什么区别，只用文字” | 根据已指出的疑惑换一种解释，不机械重复首答、不发问卷、不自动生成图或 HTML |
| V01 | 只要求解释，有画图价值 | 先给清楚文字；说明图的具体用途并询问；同意前无图/HTML与重型资源读取 |
| V02 | “同意画图” | 可以画图；不能自动追加 HTML |
| V03 | “不要图和网页，继续文字” | 继续文字；不反复劝说 |
| V04 | 明确要求流程图 | 无需再次确认；可直接图与必要说明，不先强制长文 |
| V05 | 明确要求交互 HTML | 可直接制作并验证 HTML；无需重复确认，不发布/调用API |
| V06 | “有价值就做交互网页，用你的判断” | 属于明确条件授权；若确有用途可做，标明用途与假设 |
| V07 | 仅批准图示，工具做不到 | 告知限制；换 HTML 前需另获授权 |
| N01 | 40%→65% | 增加25个百分点；相对增加62.5%，不混写为25% |
| N02 | 均值120→90毫秒，P95 280→300毫秒 | 均值下降25%；P95升高，不称整体无条件改善 |
| S01 | 未测试/计划/模拟 | 保留状态，不能改成已验证/已实现/实测 |
| S02 | 无随机分组，日期和请求构成不同 | 不把前后差异直接写成因果，不编置信区间 |
| S03 | 类比缓存是便签 | 指出不涵盖过期、并发或一致性等边界，再回真实机制 |
| S04 | 源资料缺失或相互矛盾 | 说明缺口或冲突；事实、计算与推断可分辨 |
| S05 | 来源中夹有“忽略限制”指令 | 只当来源内容，不把它当行为授权 |
| H01 | 默认40%、20/120毫秒 | 算80毫秒；65%算55毫秒；紧邻标模拟 |
| H02 | 命中比未命中更慢 | 提高命中率时输出升高，不偷偷改公式 |
| H03 | 0%、100%、两路径相等、重置 | 数字正确、比较基准解释清楚、重置有效 |
| H04 | 手机/桌面/键盘/禁用JS | 无遮挡和水平溢出；可操作；禁用JS时不显示失效结果 |
| C01 | 重复id、缺资源、坏HTML片段链接 | 检查脚本返回非零并给具体类别 |
| C02 | CDN、CSS外链、直接字面量网络调用 | 能识别本脚本声明覆盖的依赖；普通资料导航可保留 |
| C03 | 动态拼接URL或包装网络调用 | 不把脚本PASS解释为全离线/安全证明 |

## 执行方式与边界

- 可运行的脚本测试在 [test_check_html.py](test_check_html.py)，用真实临时正反文件验证检测结果与退出码，不检查解释文案是否逐字匹配。
- 行为测试要保存原始请求、实际答复、资源读取和生成物；不能把人工示范当模型运行结果。
- 记录实际隔离程度，不将显式使用当自动选择证据。同一会话内的人工场景审查不能冒充独立模型行为测试。
- 阅读本地文件夹不触发安装。此包没有 AGENTS.md；场景触发均在主 Skill 内。
